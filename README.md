# Atmanirbhar Farm 3D
Gujarati Android 3D farm-planning prototype for a nominal 310 m × 140 m plot (north at top, south at bottom, east right, west left).

Includes first-person movement, drone/orbit view, top view, labels, farmhouse and veranda/swing, garden, orchard, teak/sissoo boundary trees, crops, medicinal beds, target pond, dairy, biogas, compost, six watchtowers, oval cargo railway, wind turbine, solar/battery area, learning area/telescope, EV concept and GitHub Actions APK build.

## GitHub build
Extract this ZIP and upload its CONTENTS to the repository root. In Actions, run **Build Android APK** (or push to main). Download artifact `AtmanirbharFarm3D-debug-apk`.

## Controls
Mobile: on-screen arrows to move; drag screen to look; Drone View to orbit; Top View for aerial plan. Desktop: WASD/arrows; drag mouse to look; scroll to zoom.

## Important
This is an illustrative 3D prototype, not a surveyed construction plan. Three.js is loaded from a CDN, so internet is needed to load the 3D scene. Actual water capacity, structures, electrical systems, biogas, tracks and foundations require qualified local design and safety checks.
